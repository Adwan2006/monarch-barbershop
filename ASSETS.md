# Visual assets and provenance

All four photographs were created specifically for this project with the **built-in image generation tool**. No third-party stock photographs, logos, web fonts, celebrity likenesses, or real business imagery were sourced. The pictured people and place are fictional. AI-generated imagery is not a guarantee of exclusive rights or trademark clearance; Monarch is a concept name rather than a cleared commercial brand.

The final project-bound images are saved in `assets/images/` as WebP files at 640px and 1440px widths. The original generated PNGs were converted and resized only for delivery. The favicon is original SVG code; the map is a decorative CSS illustration, not real geographic data. Fonts use the visitor's system Georgia/Arial fallbacks and require no downloaded font license.
